# Contributing

Thank you for helping build CI Master Control Community.

1. Open an issue describing the problem or enhancement before large changes.
2. Fork and submit a focused pull request with tests and documentation.
3. Run `python3 -m unittest discover -s tests -v` locally.
4. Do not include credentials, private repository inventory, proprietary modules or sensitive CI logs.
5. Never add code that automatically runs paid CI jobs, merges pull requests or deploys software without explicit human authorization.

By submitting a contribution you agree that your contribution is licensed under Apache-2.0. Contributors retain their own copyright unless separately agreed.
