# Changelog

## 0.1.0-alpha.1 — 2026-11-19 (release candidate)

First Community alpha preview: localhost dashboard, synthetic example projects, optional server-side read-only CircleCI pipeline monitoring, historical failure flag, CLI inspector, and HTTP security smoke tests.

**Known limitations:** GitHub/CircleCI real-account integration unverified; only `gh/owner/repo` CircleCI projects; no authentication for public network access (localhost only); no repair execution; no installable OS package; no Pro sync. This is a source-distribution alpha, not a production deployment.
